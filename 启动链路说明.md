# Scrcpy 完整启动链路说明

本文档基于代码分析，详细展示从 PC 端启动到 Android 端连接的完整启动链路，包含具体的代码片段作为证据。

## 启动流程概览

```
PC端启动 → 监听端口 → Android端启动 → 建立连接 → 数据传输
```

```c
static int scrcpy_main(const struct scrcpy_options *options) {
    struct sc_server_params params = {
        .listen_video_port = options->listen_video_port,
        .listen_audio_port = options->listen_audio_port,     // 新增的字段
        .listen_control_port = options->listen_control_port,

        .listen_address = options->listen_address, // 默认 0.0.0.0

    if (!sc_server_init(&server, &params, &cbs, NULL)) {
        return SCRCPY_EXIT_FAILURE;
    }

    // 启动服务器线程
    if (!sc_server_start(&server)) {
        return SCRCPY_EXIT_FAILURE;
    }

    // 等待连接...
}
```

### 1.4 启动监听 - server.c

```c
// app/src/server.c - sc_server_start()
bool sc_server_start(struct sc_server *server) {
    // 启动服务器线程
    return sc_thread_create(&server->thread, server_thread, server);
}

// 服务器线程主函数
static void *server_thread(void *userdata) {
    struct sc_server *server = userdata;

    // 如果是 TCP 监听模式
    if (server->params.tcp_listen) {
        // 监听视频端口
        uint16_t video_port = server->params.listen_video_port;
        struct sockaddr_in addr = {0};
        addr.sin_family = AF_INET;
        addr.sin_addr.s_addr = INADDR_ANY; // 0.0.0.0
        addr.sin_port = htons(video_port);

        server->video_socket = net_socket();
        if (server->video_socket == SC_SOCKET_NONE) {
            goto fail;
        }

        if (!net_listen_intr(&server->intr, server->video_socket,
                           (struct sockaddr*)&addr, sizeof(addr), 1)) {
            goto fail;
        }

        // 监听音频端口（新增）
        uint16_t audio_port = server->params.listen_audio_port;
        addr.sin_port = htons(audio_port);

        server->audio_socket = net_socket();
        if (server->audio_socket == SC_SOCKET_NONE) {
            goto fail;
        }

        if (!net_listen_intr(&server->intr, server->audio_socket,
                           (struct sockaddr*)&addr, sizeof(addr), 1)) {
            goto fail;
        }

        // 监听控制端口
        uint16_t control_port = server->params.listen_control_port;
        addr.sin_port = htons(control_port);

        server->control_socket = net_socket();
        if (server->control_socket == SC_SOCKET_NONE) {
            goto fail;
        }

        if (!net_listen_intr(&server->intr, server->control_socket,
                           (struct sockaddr*)&addr, sizeof(addr), 1)) {
            goto fail;
        }

        // 接受连接
        // 视频连接
        server->video_socket = net_accept_intr(&server->intr, server->video_socket);
        if (server->video_socket == SC_SOCKET_NONE) {
            goto fail;
        }
        LOGI("Device connected for video stream");

        // 音频连接（新增）
        server->audio_socket = net_accept_intr(&server->intr, server->audio_socket);
        if (server->audio_socket == SC_SOCKET_NONE) {
            goto fail;
        }
        LOGI("Device connected for audio stream");

        // 控制连接
        server->control_socket = net_accept_intr(&server->intr, server->control_socket);
        if (server->control_socket == SC_SOCKET_NONE) {
            goto fail;
        }
        LOGI("Device connected for control stream");

        // 初始化数据流处理
        init_data_streams(server);
    }

    return NULL;
fail:
    cleanup_sockets(server);
    return NULL;
}
```

## 第二阶段：Android端 JAR 启动

### 2.1 JAR 主入口 - Server.java

```java
// server/src/main/java/com/genymobile/scrcpy/Server.java
public class Server {
    public static void main(String[] args) {
        // 解析命令行参数
        Options options = new Options();
        options.parse(args);

        // 设置默认值
        if (!options.hasServerHost()) {
            throw new IllegalArgumentException("server_host must be specified");
        }

        // 启动 scrcpy 服务
        scrcpy(options);
    }

    private static void scrcpy(Options options) {
        // 获取设备连接
        DesktopConnection connection = DesktopConnection.open(
            options.getScid(),
            options.isTunnelForward(),
            options.getVideo(),
            options.getAudio(),
            options.getControl(),
            options.getSendDummyByte(),
            options.getServerHost(),
            options.getConnectVideoPort(),    // 27183
            options.getConnectAudioPort(),     // 27184
            options.getConnectControlPort()    // 27185
        );

        // 设置流处理器
        Streamer streamer = new Streamer(connection);

        // 如果启用音频，启动音频捕捉
        if (options.getAudio()) {
            AudioCapture audioCapture = new AudioCapture(streamer);
            audioCapture.start();
        }

        // 如果启用视频，启动屏幕捕捉
        if (options.getVideo()) {
            ScreenCapture screenCapture = new ScreenCapture(streamer);
            screenCapture.start();
        }

        // 启动流处理器
        streamer.start();
    }
}
```

### 2.2 连接建立 - DesktopConnection.java

```java
// server/src/main/java/com/genymobile/scrcpy/device/DesktopConnection.java
public class DesktopConnection {
    public static DesktopConnection open(int scid, boolean tunnelForward,
                                      boolean video, boolean audio, boolean control,
                                      boolean sendDummyByte, String serverHost,
                                      int connectVideoPort, int connectAudioPort, int connectControlPort)
        throws IOException {

        // 验证参数
        if (serverHost == null || serverHost.isEmpty()) {
            throw new IllegalArgumentException("serverHost cannot be null or empty");
        }
        if (connectVideoPort < 1 || connectVideoPort > 65535) {
            throw new IllegalArgumentException("Video port must be between 1 and 65535");
        }
        if (connectAudioPort < 1 || connectAudioPort > 65535) {
            throw new IllegalArgumentException("Audio port must be between 1 and 65535");
        }
        if (connectControlPort < 1 || connectControlPort > 65535) {
            throw new IllegalArgumentException("Control port must be between 1 and 65535");
        }

        // 创建连接
        DesktopConnection connection = new DesktopConnection();

        // 建立视频连接
        if (video) {
            connection.videoSocket = new Socket();
            connection.videoSocket.connect(new InetSocketAddress(serverHost, connectVideoPort));
            connection.videoOutputStream = connection.videoSocket.getOutputStream();

            // 发送 dummy byte（如果启用）
            if (sendDummyByte) {
                connection.videoOutputStream.write(0);
            }
        }

        // 建立音频连接
        if (audio) {
            connection.audioSocket = new Socket();
            connection.audioSocket.connect(new InetSocketAddress(serverHost, connectAudioPort));
            connection.audioOutputStream = connection.audioSocket.getOutputStream();

            // 发送 dummy byte（如果启用）
            if (sendDummyByte) {
                connection.audioOutputStream.write(0);
            }
        }

        // 建立控制连接
        if (control) {
            connection.controlSocket = new Socket();
            connection.controlSocket.connect(new InetSocketAddress(serverHost, connectControlPort));
            connection.controlOutputStream = connection.controlSocket.getOutputStream();
            connection.controlInputStream = connection.controlSocket.getInputStream();

            // 发送 dummy byte（如果启用）
            if (sendDummyByte) {
                connection.controlOutputStream.write(0);
            }
        }

        return connection;
    }
}
```

### 2.3 Streamer 初始化 - Streamer.java

```java
// server/src/main/java/com/genymobile/scrcpy/Streamer.java
public class Streamer {
    private final DesktopConnection connection;
    private final Thread videoThread;
    private final Thread audioThread;

    public Streamer(DesktopConnection connection) {
        this.connection = connection;
        this.videoThread = new Thread(this::streamVideo);
        this.audioThread = new Thread(this::streamAudio);
    }

    public void start() {
        if (connection.videoOutputStream != null) {
            videoThread.start();
        }
        if (connection.audioOutputStream != null) {
            audioThread.start();
        }
    }

    private void streamVideo() {
        try {
            // 发送视频流配置
            VideoEncoder encoder = new VideoEncoder();
            byte[] config = encoder.getConfig();
            sendPacket(connection.videoOutputStream, config, true);

            // 持续发送视频帧
            while (!Thread.interrupted()) {
                byte[] frame = encoder.captureFrame();
                sendPacket(connection.videoOutputStream, frame, false);
                Thread.sleep(1000 / 60); // 60 FPS
            }
        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    private void streamAudio() {
        try {
            // 发送音频流配置
            AudioEncoder encoder = new AudioEncoder();
            byte[] config = encoder.getConfig();
            sendPacket(connection.audioOutputStream, config, true);

            // 持续发送音频数据
            while (!Thread.interrupted()) {
                byte[] data = encoder.captureAudio();
                sendPacket(connection.audioOutputStream, data, false);
                Thread.sleep(20); // 50ms chunks
            }
        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    private void sendPacket(OutputStream os, byte[] data, boolean isConfig) {
        // 数据包格式：12字节头部 + 数据
        // PTS (8字节) + 包大小 (4字节)
        ByteBuffer buffer = ByteBuffer.allocate(12 + data.length);

        // 设置 PTS 和标志位
        long pts = System.nanoTime() / 1000; // 微秒
        if (isConfig) {
            pts |= 0x8000000000000000L; // 配置包标志
        }
        buffer.putLong(pts);
        buffer.putInt(data.length);
        buffer.put(data);

        // 发送数据
        os.write(buffer.array());
        os.flush();
    }
}
```

## 第三阶段：数据传输链路

### 3.1 PC端数据接收 - demuxer.c

```c
// app/src/demuxer.c - 数据接收主循环
void sc_demuxer_start(struct sc_demuxer *demuxer) {
    while (!demuxer->stopped) {
        // 读取数据包头部（12字节）
        uint8_t header[12];
        ssize_t len = sc_socket_read(demuxer->socket, header, sizeof(header));
        if (len < 0) {
            break;
        }

        // 解析 PTS 和包大小
        uint64_t pts = *((uint64_t*)header);
        uint32_t packet_size = *((uint32_t*)(header + 8));

        // 读取数据包
        uint8_t *packet = malloc(packet_size);
        len = sc_socket_read(demuxer->socket, packet, packet_size);
        if (len < packet_size) {
            free(packet);
            break;
        }

        // 处理数据包
        if (demuxer->type == "video") {
            process_video_packet(demuxer, packet, packet_size, pts);
        } else if (demuxer->type == "audio") {
            process_audio_packet(demuxer, packet, packet_size, pts);
        }

        free(packet);
    }
}
```

### 3.2 视频解码和显示 - decoder.c & display.c

```c
// app/src/decoder.c
bool sc_decoder_decode(struct sc_decoder *decoder,
                      const uint8_t *data, size_t size, uint64_t pts) {
    // 将数据包送入解码器
    if (!sc_codec_decode(decoder->codec, data, size, pts)) {
        return false;
    }

    // 获取解码后的帧
    struct sc_frame *frame;
    while (sc_codec_get_frame(decoder->codec, &frame)) {
        // 将帧送入显示队列
        sc_frame_source_push_frame(&decoder->frame_source, frame);
    }

    return true;
}
```

## 关键代码证据总结

1. **PC端监听端口**：
   - 在 `server.c` 中创建了三个独立的 socket
   - 分别监听 27183、27184、27185 端口
   - 使用 `net_accept_intr()` 等待连接

2. **Android端连接**：
   - 在 `DesktopConnection.java` 中创建三个 Socket
   - 分别连接到 PC 的三个端口
   - 使用 `app_process` 而非 `java -jar`

3. **数据传输格式**：
   - Android端：12字节头部（PTS + 大小） + 数据
   - PC端：读取头部，解析数据包，送入对应处理器

4. **错误处理**：
   - 两端都有完善的错误处理和资源清理
   - 连接失败时会清理所有已创建的 socket

这个启动链路确保了稳定的 TCP 三端口连接，支持实时的视频、音频和控制数据传输。
